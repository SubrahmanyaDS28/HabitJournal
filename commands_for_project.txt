🔄 The Daily Cycle: Using push and pull
Once your workspace link is established, your normal git cycle boils down to a few basic terms:

git pull: Downloads and merges any updates from GitHub down to your computer. Run this before you start writing any new features to ensure you have the latest code version if you happen to modify it from another PC.

git status: Checks to see what files you have modified since your last save.

git add .: Groups your modified scripts together for staging.

git commit -m "Brief description of changes": Packages the changes up into a fresh checkpoint.

git push: Sends those local commits up to your GitHub dashboard online.
